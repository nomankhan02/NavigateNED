# Design Guidelines & System Constraints

## Banned Patterns & Anti-Patterns
- **No AI-Generic Look**: No boilerplate templates, no interchangeable corporate dashboard appearance.
- **No Purple/Blue-Purple Gradients**: Strictly forbidden. Use tailored architectural campus tones.
- **No Edge-to-Edge Padding-less Layouts**: Maintain deliberate structural whitespace, grids, and breathable margins.
- **No Default/Generic Fonts or Themes**: No system fallback look or default browser styles. Typography must feel institutional and purposeful.
- **No Emojis Anywhere**: Text, labels, alerts, notifications, and UI components must not use emoji characters.
- **No Icon Libraries**: No Lucide, Heroicons, FontAwesome, or Feather. Every icon must be a custom, hand-drawn inline SVG following a unified design grid (fixed viewport, identical stroke width, consistent cap and join geometry).
- **Aesthetic Balance**: Neither overly brutalist/minimalist nor cluttered with decorative noise. Functional, elegant, and legibly engineered.
- **Motion Principles**: Animations must be purposeful (guiding navigational focus), brief, and strictly respect `prefers-reduced-motion` media queries.
