# Repository Map

- `agents.md`: Unified project ownership table and 5-step task workflow.
- `contracts.md`: Data schemas and C++ WASM API interface contract.
- `design.md`: Campus Survey Plate visual direction, token architecture, typography, vellum rules, and motion spec.
- `memory.md`: Living project state, architectural decisions, and current issues (<100 lines).
- `plan.md`: Roadmap and task breakdown assigned by team member.
- `README.md`: Project overview, architecture summary, and instructions to run locally.
- `repo_map.md`: Single-line directory and file index.
- `rules.md`: Core architectural principles, git rules, code guidelines, and token rules.
- `vercel.json`: Vercel static export deployment configuration.
- `.gitignore`: Git ignore patterns for Node, C++, build caches, .ref/, and WASM build outputs.
- `.github/workflows/core.yml`: CI pipeline for building/testing native C++ and compiling WASM.
- `core/`: C++17 DSA algorithmic engine and Emscripten bindings.
- `core/CMakeLists.txt`: Build specification for native test target and Emscripten WASM target.
- `core/src/navcore.cpp`: Single-file C++17 DSA, routing, evacuation, turn-by-turn navigation & viva CLI showcase engine (Graph, Dijkstra, A*, BFS, Bellman-Ford, Trie search, LRU cache, Floyd-Warshall, Union-Find + Kruskal/Prim MST, Held-Karp DP/NN TSP, Tarjan critical points, Multi-Source Reversed Dijkstra + Min-Cost Max-Flow SPFA evacuation, turn-by-turn directions, GPS progress & live rerouting, WASM `call()`, and `NAVCORE_CLI` ASCII map/animation/demo showcase).
- `core/tests/test_main.cpp`: Native Doctest unit test suite `#include`-ing `core/src/navcore.cpp`.
- `core/third_party/doctest/doctest.h`: Vendored single-header unit testing framework.
- `core/third_party/nlohmann/json.hpp`: Vendored single-header JSON parser.
- `data/`: Campus graph datasets and geo specifications.
- `data/evac.json`: Emergency evacuation dataset (7 assembly areas, 12 building exits across 6 indoor buildings).
- `data/graph.json`: Georeferenced campus road network (86 nodes, 108 edges, 55 landmarks).
- `data/sample/graph.json`: 4-node sample graph for scaffolding and WASM bridge verification.
- `data/indoor/`: Directory for indoor building floor navigation data.
- `data/indoor/b-admin.json`: Admin Block indoor graph (ring 70x44m, 3 floors, 54 rooms).
- `data/indoor/b-auditorium.json`: Main Auditorium indoor graph (U 70x50m, 2 floors, 26 rooms).
- `data/indoor/b-csit.json`: CSIT & Maths indoor graph (ring 70x44m, 3 floors, 48 rooms).
- `data/indoor/b-csit-labs.json`: CSIT Labs (5A) indoor graph (U 70x50m, 2 floors, 32 rooms).
- `data/indoor/b-dean-offices.json`: Dean Offices indoor graph (L 60x60m, 2 floors, 32 rooms).
- `data/indoor/b-library.json`: Central Library indoor graph (H 70x56m, 3 floors, 48 rooms).
- `tools/`: Utility scripts for data processing and map extraction.
- `tools/.gitignore`: Git ignore rule excluding generated floor preview PNGs (`previews/`).
- `tools/add_geometry.py`: Re-runnable footpath geometry and honest edge weight generator snapping to OSM ways and building exterior perimeters.
- `tools/extract_ned.py`: Re-runnable georeferenced dataset extraction pipeline from TraverseNED.
- `tools/generate_evac.py`: Re-runnable emergency evacuation assembly areas and building exits generator.
- `tools/generate_indoor.py`: Re-runnable multi-floor indoor graph and PNG preview generator for 6 buildings.
- `tools/sync_indoor_public.py`: Re-runnable sync script copying data/indoor/*.json to web/public/data/indoor/.
- `tools/validate.py`: Schema and graph topology validation tool checking outdoor, indoor, and evacuation contracts.
- `tools/warp_master_plan.py`: Re-runnable Pillow/NumPy script warping `ned_master_plan.jpg` into a north-up georeferenced RGBA WebP and updating `graph.json` `meta.warpedOverlay`.
- `web/`: Next.js 15 App Router static export frontend.
- `web/package.json`: Web dependencies, scripts, and build tasks.
- `web/tsconfig.json`: TypeScript compiler configuration with strict checks.
- `web/next.config.ts`: Next.js config with static export, cache headers, and `devIndicators` disabled.
- `web/public/favicon.svg`: Static 30° isometric "N" Harbor Chart vector favicon.
- `web/public/apple-touch-icon.png`: 180x180 anti-aliased isometric "N" app icon.
- `web/public/data/evac.json`: Static public emergency evacuation dataset (7 assembly areas, 12 building exits).
- `web/public/data/graph.json`: Static public campus graph dataset for web runtime consumption.
- `web/public/data/indoor/`: Static public indoor floor plan datasets for client-only loading.
- `web/public/map/ned_master_plan.jpg`: Calibrated master plan map overlay source image.
- `web/public/map/ned_master_plan_warped.webp`: North-up georeferenced RGBA WebP master plan overlay for `L.imageOverlay(bounds)`.
- `web/public/wasm/navcore.js`: Compiled/committed WASM JavaScript loader and module.
- `web/src/app/layout.tsx`: Root layout loading self-hosted Bricolage Grotesque, Familjen Grotesk, Azeret Mono, and Campus Survey Plate tokens.
- `web/src/app/page.tsx`: Home route mounting the Campus Survey Plate `AppShell` over full-bleed `OutdoorMap`.
- `web/src/app/kit/page.tsx`: Interactive `/kit` showcase of all Campus Survey Plate tokens, typography, icons, and UI components in Daylight and Night modes.
- `web/src/app/kit/kit.module.css`: Scoped layout styles for the `/kit` styleguide page.
- `web/src/app/_map-dev/page.tsx`: Temporary dev harness page verifying `OutdoorMap`, `useTraceReplay`, and evacuation overlays.
- `web/src/app/_map-dev/indoor/page.tsx`: Temporary dev harness page verifying `IndoorMap` multi-floor rendering, evacuation, and trace replay.
- `web/src/app/%5Fmap-dev/page.tsx`: Next.js App Router URL-encoded underscore route wrapper for `/_map-dev`.
- `web/src/app/%5Fmap-dev/indoor/page.tsx`: Next.js App Router URL-encoded underscore route wrapper for `/_map-dev/indoor`.
- `web/src/core/navcore.ts`: Typed TypeScript client bridge calling WASM runtime (`ensureAllCampusDataLoaded`, `computeRoute`, `getDirections`, `compareAlgorithms`, `searchCampus`).
- `web/src/map/`: Map rendering canvas and SVG components (owned by Member A).
- `web/src/map/geometry.ts`: Polyline geometry helpers resolving edge geometries, traversal orientation, path stitching, and straight-line fallbacks.
- `web/src/map/index.ts`: Barrel exports for `OutdoorMap`, `useTraceReplay`, geometry helpers, and all map TypeScript interfaces.
- `web/src/map/indoor/`: Multi-floor architectural indoor SVG map renderer and components.
- `web/src/map/indoor/floors.tsx`: Multi-floor state helpers and vertical floor switcher component.
- `web/src/map/indoor/indoor.css`: Scoped CSS tokens and architectural styling for IndoorMap.
- `web/src/map/indoor/IndoorMap.tsx`: Client-only SVG multi-floor indoor architectural building viewer.
- `web/src/map/indoor/labels.ts`: Responsive room label fitting with SVG clipPath boundary clipping, 2-line wrapping down to 9px, and short code fallback.
- `web/src/map/indoor/route.ts`: Indoor route processing, floor-specific path extraction, and vertical transitions.
- `web/src/map/indoor/types.ts`: TypeScript contracts for IndoorBuilding, IndoorMapProps, and indoor nodes/edges.
